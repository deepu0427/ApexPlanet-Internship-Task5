📖 Overview
This project is a front‑end simulation of an advanced e‑commerce website built with HTML, CSS, and JavaScript. It replicates essential features of online shopping platforms, including product display, cart management, login/logout functionality, search and filtering, dark mode support, and responsive design.

✨ Features
Product Listing: Dynamic product cards with images, names, prices, and “Add to Cart” buttons.

Cart System:

Add/remove items with quantity updates.

View cart contents and total price.

Cart data persists using localStorage.

Login/Logout:

Modal prompts user to enter a username.

Username saved in localStorage.

Modal hides after login and reappears after logout.

Search and Filter:

Search bar filters products by name.

Dropdown filter allows category selection (fashion/electronics).

Combined search + filter functionality.

Dark Mode Toggle: Switch between light and dark themes.

Responsive Design: Cart adapts to mobile screens by expanding to full width.

🎯 Purpose
This project provides hands‑on practice in:

DOM manipulation with JavaScript.

Using localStorage for state persistence.

Building interactive UI components (modal, cart, filters).

Applying responsive design principles.

Structuring a small but complete web application.

🧑‍💻 Learning Outcomes
By completing this project, you gain experience in:

Creating dynamic web pages.

Managing application state with localStorage.

Implementing simple authentication simulations.

Designing responsive layouts.

Building a foundation for full‑stack development.
